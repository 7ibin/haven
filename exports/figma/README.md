# Haven → Figma (Home screen)

Captured from `http://localhost:8080/` (Home tab, logged-in demo state).

| File | Use in Figma |
|------|----------------|
| `home-viewport-390x844.png` | Single mobile frame — drag onto canvas or **Place image** (390×844 @2x) |
| `home-full.png` | Full scrollable home page as one image |
| `home-browser.png` | Desktop-width capture (if present) |

## Editable layers (recommended)

For real Figma layers (not flat images):

1. Run `serve.ps1` and open **Chrome** (not Cursor’s built-in browser).
2. [html.to.design extension](https://chromewebstore.google.com/detail/htmltodesign/ldnheaepmnmbjjjahokphckbpgciiaed) → **Capture** on this URL.
3. [html.to.design Figma plugin](https://www.figma.com/community/plugin/1159128660497570987) → import capture.

## Design tokens

Import `../design-tokens.json` via [Tokens Studio](https://tokens.studio/) for colors, spacing, and radii.
